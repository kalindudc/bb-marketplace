Delegate bb's helper AI tasks to the pi CLI on your machine.

## What you get

- bb's thread titles and commit messages generated by your own pi setup: your credentials, your model, your defaults — no bb account or separate API key needed.
- A Model knob and a Pi executable knob under Settings → Installed plugins → Pi AI Services (also editable with `bb plugin config pi-services`).
- A refresh button in the thread header that regenerates the current thread's title on demand, and the same action as **Regenerate title with pi** in every thread's actions menu. Phones get only the menu item, to keep their header uncluttered.

## How it works

The plugin registers a bb AI service that runs `pi --print --no-session --no-tools` on the machine that runs the bb server, optionally passing `--model` from the settings. bb calls it for thread titles and commit messages and cleans up the reply itself. The regenerate button and menu item call the plugin's own RPC, which asks pi for a fresh title and renames the thread.

Select the service under Settings → AI services, or run:

```sh
bb settings ai-services set thread-title pi
bb settings ai-services set commit-message pi
```

Automatic picks Pi CLI when bb cloud is not signed in.

## Limits

Text only: voice transcription is not provided. The pi CLI must be installed and signed in on the machine that runs the bb server; the plugin launches it as a one-shot process, so every call pays pi's startup cost. pi's tools are disabled (`--no-tools`) because bb asks for plain-text replies, and bb aborts text services after five seconds.
