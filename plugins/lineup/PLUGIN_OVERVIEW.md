Pick a model from a short list instead of scrolling or searching through every provider and model bb knows about, without leaving bb's own model menu.

## What you get

- Two tabs at the start of bb's model menu, before its provider tabs: **Recent** and **Lineup**. When only one provider is enabled and bb draws no tabs, Lineup adds the row with an **All models** tab for bb's own list.
- **Recent** lists the models your threads ran on most recently, newest first, with how long ago each was used. It reads them from your thread history, so it is full from the first day. Set how many it shows under **Models in Recent** in the plugin's settings (25 by default).
- **Lineup** is a list of models you choose. Hover a model in any tab, including bb's own lists, and click its pin to add it or take it out.
- Picking a row switches the composer's model just as picking it in bb's list does, and the menu stays open so you can change the reasoning level too.
- Typing in the search box filters Recent or Lineup and also lists matching models from every provider underneath, so you can find and pin any model without changing tabs.
- **Tab** and **Shift+Tab** in the search box move between Recent, Lineup and bb's list; the arrow keys and Enter work as in bb's list.
- The menu opens on the tab you used last. Until you choose Recent or Lineup it opens on bb's own list, as it always has.
- **Settings → Plugins → Lineup** reorders the lineup, removes models from it and adds any model with bb's own picker.
- It works in the New thread composer and in a thread's composer. The lineup and the last tab are saved on the bb server, so every window shares them.

## Limits

- bb has no plugin interface for its model menu, so Lineup adds its tabs to the menu bb 0.47 draws. If a bb update changes that menu, the tabs stop appearing until Lineup is updated; bb's own menu keeps working.
- Lineup does not change bb's own lists; it only adds the two tabs and the pins.
- A model that is not offered on this machine, for example because its provider is disabled, is left out of Recent and shown as "not offered here" in Lineup.
- Recent reads at most the 400 most recently active threads, so a long-unused model can drop off before the limit is reached.
