## Journal compatibility alias

The thread checklist is now the journal. A board quest remains a goal a Keeper holds.

Read the single current guide by calling `journal` with `action: "skill"` (or `action: "rules"`). An existing session that exposes only the deprecated `quest` tool can call `quest` with the same action; both return the canonical journal guide. Use the canonical `journal` tool and skill whenever available.
